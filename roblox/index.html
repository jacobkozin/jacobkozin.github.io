One server owns a player's data at a time

A quick rejoin can load stale data on a new server while the old one is still saving, which is how items get duplicated. A session lock makes the new server wait, and a server that loses its lock stops writing.

src/DataService.luau
store:UpdateAsync(key, function(saved)
  saved = saved or deepCopy(CONFIG.Template)
  local lock = saved._lock
  local lockedElsewhere = lock ~= nil
    and lock.job ~= game.JobId
    and os.time() - lock.time < CONFIG.LockStaleAfter
  if lockedElsewhere and not force then
    blocked = true
    return nil -- cancel the write; another server still owns this data
  end
  saved._lock = { job = game.JobId, time = os.time() }
  result = saved
  return saved
end)

A purchase is confirmed only after it is saved

If a server confirms a developer product and then fails before saving, the player paid and lost the item. Here the receipt id is stored with the reward, and Roblox is told "granted" only once that save succeeds. Retries check the list first.

src/ShopService.luau
table.insert(data.ProcessedReceipts, receipt.PurchaseId)

-- Only confirm once the grant and the receipt are safely saved. If this
-- save fails, the receipt is still recorded in memory, so the retry
-- saves again instead of granting twice.
if not DataService.SaveNow(player) then
  return Enum.ProductPurchaseDecision.NotProcessedYet
end
return Enum.ProductPurchaseDecision.PurchaseGranted

The shop never trusts the client

Purchase requests are rate limited per player, and the server checks the type, the item, ownership and the balance before anything changes.

src/ShopService.luau
local function purchase(player: Player, itemId: unknown)
  local now = os.clock()
  if now - (lastRequest[player] or 0) < REQUEST_COOLDOWN then
    return { ok = false, reason = "TooFast" }
  end
  lastRequest[player] = now

  -- Never trust the client: validate the type and that the item exists.
  if type(itemId) ~= "string" then
    return { ok = false, reason = "BadRequest" }
  end
  local item = CATALOG[itemId]
  if not item then
    return { ok = false, reason = "UnknownItem" }
  end
  -- ... then: data loaded, not already owned, enough coins
end
